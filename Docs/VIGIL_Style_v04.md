# VIGIL — vanilla-expanded-inspired sprite revision v0.4

Three original horizontal weapon sprites with the same recognisable form, one for each state.

- Style: strong readable silhouette, cleaner hand-painted facets, restrained gold and navy detailing.
- Palette: pale steel, royal gold, graphite grip; cyan rune accents reserved for unlocked stages.
- Each texture is 512x512 RGBA with transparent padding; the actual weapon graphic occupies the center horizontal area and faces right.
- The visuals are original project artwork; not official Vanilla Expanded assets.
- The 1.6 XML-only preview still has three separate test weapons; the source project has not yet implemented a runtime texture-state swap.
- No C# compile or in-game test has been conducted for this art pass.
